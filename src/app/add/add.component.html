Contribute

Add a source or a dataset

The catalog is curated by hand, by editors, against the published methodology. There is no submission form yet — that is on the roadmap, but for now the most reliable way to propose an addition is by email.

Write to index@openhistorymap.org with:

  • · A short description of the source or dataset and why it belongs in the index.
  • · A link to the canonical version (publisher, repository, archive, or PDF).
  • · The period and territory it covers, however roughly.
  • · The authors or compilers, if known.

We’ll write back. Additions are reviewed against the methodology and the index grows slowly, in public. Thank you for filling in the blanks.

For editors

The catalog is kept inside a shared Zotero group library. Editors classify each record with OHM-specific tags (ohm:area, ohm:from_time, ohm:to_time, ohm:topic, ohm:source_reliability, ohm:source_quality…) defined by the methodology. Two companion tools make this easier:

  • ohm-zotero

    A Zotero plugin that adds an editor for the ohm:* tags directly inside the item pane: pick an area, set the period, choose a topic from the controlled list, assign quality and reliability. Keeps every record in step with the index methodology.

  • ohm-zotero-chrome

    A Chrome extension that attaches the current page (or any picked link) as a linked-URL attachment to an existing Zotero item — useful when curating sources you find while reading on the web.
